# BlogNet

**BlogNet** is a decentralized blogging network application based on P2P technology.

## Features
- Fully decentralized P2P architecture (no central servers).
BlogNet is designed as a blogging application that does not depend on companies or external funding. We won’t "pay you to use the network"—we are not part of the "decentralized network" scams that exploit your device to mine cryptocurrencies—nor do we ask for donations.
BlogNet is built on peer-to-peer principles: a direct connection between peers, with no central servers, where every user acts as both a client and a server.
We have no business model; BlogNet is free—not because the user is the product, and not because we harvest your personal data to sell to advertising firms.
It is free because it didn't cost money to create—only effort—which we are happy to gift to humanity.
BlogNet is our gift to the world, demonstrating the possibility of an internet that doesn't rely on corporations, but rather on tools designed for the free exchange of ideas.

## What you can currently do with BlogNet:
- Write articles using rich text (bold, italics).
- Insert images.
- Add tags and categories, and specify the language of an article (by default, it detects your operating system's language if you don't select one).
- Follow and back up an author: whenever both you and the author are online, BlogNet will request an updated catalog of their articles—including any subsequent edits. In doing so, you become a replica of their content, keeping it available online even when the original author is offline. - You can create thematic collections of your downloaded articles—a sort of "reading playlist" (a "readlist," perhaps?)—which other users can download from your profile in EPUB format. In this way, you become a content curator—your own personal "Reader's Digest."
- You can tag other authors using the same tags you apply to topics; however, any tagged individual has the unilateral right to remove that tag without prior notice.
- You have a "right to digital oblivion": if you decide that an article should no longer be available, deleting it sends a signal across the entire network. The next time a user who has saved one of your articles connects to the platform, they will receive a notification to remove that item, which will then happen automatically—no further action required.
## Planned features:

- Switch to a wxPython rendering engine for better integration with Linux and Windows.
- Develop a version for macOS.
- Replace the current rich-text editing and viewing system with assisted HTML to offer users more options.
- Add a "Trending This Week" feature.
- Translate the interface into all European languages, as well as Arabic, Japanese, and Chinese.
