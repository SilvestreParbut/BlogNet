# BlogNet

**BlogNet** is a decentralized, P2P-based blogging network application.

## Features
- Fully decentralized P2P architecture (no central servers).
- Global discovery via DHT.
- Three modes: Browse, Follow, and Follow & Backup.
- Built-in reputation system based on curations.
- Tombstone mechanism for content deletion.
